# Customer Sentiment Analysis Dashboard

## Project Overview
This project presents an interactive Customer Sentiment Analysis Dashboard built using Microsoft Power BI and an Amazon customer reviews dataset.

The dashboard helps explore customer review patterns, sentiment distribution, product ratings, and category-wise feedback.

## Dashboard Features
- Total Reviews and Average Rating KPIs
- Positive, Negative, and Neutral Sentiment Distribution
- Sentiment Analysis by Category
- Reviews by Rating
- Interactive Category and Rating Filters
- Visual insights into customer review patterns

## Tools Used
- Microsoft Power BI
- Data Visualization
- Amazon Customer Reviews Dataset

## Project Files
- `Customer_Sentiment_Analysis_Dashboard.pbix` — Power BI dashboard file
- `Customer_Sentiment_Analysis_Dashboard.png` — Dashboard screenshot

## Purpose
The objective of this project is to explore customer sentiment patterns and present review data in an interactive, easy-to-understand dashboard.

## Note
The sentiment categories displayed in this dashboard were available in the source dataset. This project focuses on visualizing and exploring those existing labels.
